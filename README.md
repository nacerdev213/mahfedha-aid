# 🎒 منظومة تسجيل وتوزيع المحافظ المدرسية (v1.4.0)

> تطبيق مكتبي حديث وسريع مخصص للجمعيات الخيرية ولجان التضامن لإحصاء، تسجيل، وتسيير توزيع المحافظ والأدوات المدرسية على مستحقيها عبر الأطوار التعليمية الثلاثة (ابتدائي، متوسط، ثانوي).

---

## ✨ المميزات الرئيسية
- 🚀 **واجهة عصرية وسريعة جداً:** مبنية باستخدام Vue 3 + Tailwind CSS مع دعم كامل وشامل للغة العربية من اليمين إلى اليسار (RTL).
- 💾 **قاعدة بيانات محلية ذاتية (SQLite + Rust Tauri):** بدون الحاجة لأي خادم أو اتصال بالإنترنت، مع الحفاظ الكامل على سرية وأمان بيانات العائلات.
- 👨‍👩‍👧‍👦 **إدارة شاملة للمستفيدين:** بيانات ولي الأمر، الأطفال المتمدرسين، والحالة الاجتماعية مع حماية ذكية ضد التكرار.
- 🏫 **إدارة وتخصيص الأطوار والسنوات الدراسية:** إمكانية إضافة وحذف وتعديل المستويات الدراسية مع ربط مباشر بالأطفال المسجلين.
- 📊 **لوحة إحصائيات وتحليل شامل:**
  - نسب التسليم الميداني المباشر (المسلّم vs المتبقي في الانتظار).
  - توزيع المحافظ حسب الأطوار التعليمية (ابتدائي، متوسط، ثانوي).
  - توزيع الأطفال المتمدرسين حسب السنة الدراسية مع تفصيل دقيق لكل طور وسنة (عدد المسلّم، عدد في الانتظار، والمجموع).
  - توزيع المستفيدين حسب الحالات الاجتماعية ونسبها المئوية.
- 🔄 **إدارة المواسم الدراسية:** إمكانية إنشاء مواسم جديدة وترحيل بيانات الأسر تلقائياً بين السنوات بنقرة زر.
- 🔢 **فحص تسلسل الأرقام والفجوات:** كشف أرقام السجلات الغائبة وتوفير إمكانية ملئها تلقائياً وفورياً.
- 🖨️ **طباعة محاضر واستمارات رسمية متقدمة:**
  - طباعة استمارات الدخول المدرسي الفردية والجماعية.
  - طباعة قوائم محاضر التسليم بتنسيق عرضي (Landscape) أو طولي (Portrait).
  - خيارات طباعة مخصصة بنطاق أرقام، أو للمحددين فقط، أو للكل، أو طباعة استمارات فارغة.
- 📥📤 **استيراد وتصدير إكسيل (Excel):** دعم كامل لقراءة وتوليد ملفات XLSX وقوالب الإدخال المعتمدة.

## 🆕 الجديد في الإصدار v1.4.0
- ✨ **تحليل توزيع الأطفال المتمدرسين في لوحة التحكم:** إظهار عدد الأطفال المسلّم لهم، عدد الأطفال في الانتظار، والمجموع لكل طور ولكل سنة دراسية على حدة مع أشرطة تقدم بصرية.
- ⚡ **تحديث لحظي للإحصائيات:** مزامنة فورية لإحصائيات السنوات الدراسية عند تغيير حالة الاستلام أو تبديل الموسم.
- 🏫 **إدارة مخصصة للسنوات الدراسية:** إضافة نافذة مخصصة لإدارة سنوات كل طور دراسي ومزامنتها تلقائياً مع السجلات.
- 🖨️ **تحسينات خيارات الطباعة المخصصة:** مرونة تامة في اختيار نطاق السجلات والتحكم في الاتجاه والعدد.

## 🛠️ للمطورين (Development)

### المتطلبات
- Node.js (v18+)
- Rust & Cargo
- أدوات Microsoft C++ Build Tools

### خطوات التشغيل المحلي
```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل بيئة التطوير
npm run dev

# أو تشغيل التطبيق في بيئة سطح المكتب:
npx tauri dev
```

### بناء حزم التثبيت (32-bit Release)
```bash
npm run build:32:installer
```
تجد الملفات الناتجة في مجلد:
`src-tauri/target/i686-pc-windows-msvc/release/bundle/`
