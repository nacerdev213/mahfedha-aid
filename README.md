# 🎒 منظومة تسجيل وتوزيع المحافظ المدرسية (v1.3.1)

> تطبيق مكتبي حديث وسريع مخصص للجمعيات الخيرية ولجان التضامن لإحصاء، تسجيل، وتسيير توزيع المحافظ والأدوات المدرسية على مستحقيها عبر الأطوار التعليمية الثلاثة (ابتدائي، متوسط، ثانوي).

---

## ✨ المميزات الرئيسية
- 🚀 **واجهة عصرية وسريعة جداً:** مبنية باستخدام Vue 3 + Tailwind CSS مع دعم كامل للغة العربية (RTL).
- 💾 **قاعدة بيانات محلية ذاتية (SQLite + Rust Tauri):** بدون الحاجة لأي خادم أو اتصال بالإنترنت، مع الحفاظ الكامل على سرية بيانات العائلات.
- 👨‍👩‍👧‍👦 **إدارة شاملة للمستفيدين:** بيانات ولي الأمر، الأطفال المتمدرسين، والحالة الاجتماعية مع حماية ضد التكرار.
- 🔄 **إدارة المواسم الدراسية:** إمكانية إنشاء مواسم جديدة وترحيل بيانات الأسر تلقائياً بين السنوات.
- 📊 **لوحة إحصائيات دقيقة:** نسب التسليم الميداني، توزيع المحافظ حسب الطور، وتوزيع الأسر حسب الحالات الاجتماعية.
- 🔢 **فحص تسلسل الأرقام والفجوات:** كشف أرقام السجلات الغائبة وتوفير إمكانية ملئها فوراً.
- 🖨️ **طباعة محاضر واستمارات رسمية:** طباعة قوائم التوزيع واستمارات الدخول المدرسي الفردية بدقة فائقة.
- 📥📤 **استيراد وتصدير إكسيل (Excel):** دعم كامل لقراءة وتوليد ملفات XLSX وقوالب الإدخال المعتمدة.

## 🛠️ للمطورين (Development)

### المتطلبات
- Node.js (v18+)
- Rust & Cargo
- أدوات Microsoft C++ Build Tools

### خطوات التشغيل المحلي
```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل بيئة التطوير
npm run dev

# أو تشغيل التطبيق في بيئة سطح المكتب:
npx tauri dev
```

### بناء حزم التثبيت (32-bit Release)
```bash
npm run build:32:installer
```
تجد الملفات الناتجة في مجلد:
`src-tauri/target/i686-pc-windows-msvc/release/bundle/`
