## 📖 حول المنظومة

صُممت هذه المنظومة خصيصاً لتلبية احتياجات **الجمعيات الخيرية، الهلال الأحمر، ولجان التضامن المدرسي** لإدارة حملات الدخول المدرسي بكفاءة ودقة عالية. يوفر التطبيق بيئة عمل مغلقة وآمنة **(100% Offline)** تحمي خصوصية بيانات العائلات المعوزة والأيتام بدون الاعتماد على أي خوادم خارجية أو اشتراكات سحابية، مع أداء فائق وسرعة استجابة لحظية بفضل نواة **Rust** وتقنية **Tauri**.

## 🆕 الجديد في الإصدار v1.6.0

يُعد الإصدار **v1.6.0** ترقية بصرية ووظيفية كبرى تركز على تحسين تجربة انطلاق التطبيق، القضاء على وميض الشاشة البيضاء، وتوفير دليل استخدام مدمج ووسائل دعم مباشر:

### 1. 🚀 شاشة بدء تشغيل تفاعلية بنمط Microsoft Office (Office-Style Splash Screen)
- **القضاء التام على وميض الشاشة البيضاء (Zero White Flash):** تبدأ المنظومة فورياً بعرض شاشة انطلاق خفيفة وفائقة السرعة في أجزاء من الثانية بينما يتم تجهيز قاعدة البيانات وتحميل السجلات في الخلفية.
- **نافذة تفاعلية قابلة للسحب والتحريك (Draggable):** إمكانية مسك شاشة الانطلاق وتحريكها بحرية في أي مكان على سطح المكتب بفضل خاصية `data-tauri-drag-region` وتكامل محرك Tauri الأصلي.
- **إمكانية الإغلاق الفوري دون إغلاق البرنامج:** زر إغلاق أنيق `✕` واختصار `Esc` يسمح للمستخدم بتخطي شاشة البدء فوراً والدخول إلى التطبيق، مع ضمان استمرار البرنامج وعدم إنهائه.
- **تصميم Fluent أنيق وعصري:** بطاقة داكنة راقية بتأثير الزجاج والظلال العميقة، شريط تقدم أملس مستوحى من برامج Office، ونصوص حالة ديناميكية متغيرة توضح مراحل التهيئة خطوة بخطوة.

### 2. 📖 مركز المساعدة ودليل الاستخدام التفاعلي الشامل (Interactive Help Center)
- **دليل مدمج ومفصل يغطي كافة أركان التطبيق:** 13 قسماً مدعماً بالرسوم والبطاقات التوضيحية يشمل دورة العمل الميداني، إدارة المستفيدين، الصور والماسح، الحالات الاجتماعية ونظام التنقيط، لوحة التحكم، استيراد وتصدير Excel، الطباعة المتقدمة، ترحيل المواسم، فحص الفجوات، النسخ المشفر وضبط المصنع، وهوية الجمعية.
- **محرك بحث فوري وتصفح سريع:** بحث لحظي بالعربية عن أي كلمة مفتاحية مع فلاتر سريعة وفهرس تفاعلي للأقسام.
- **وصول فوري من أي مكان:** متوفر عبر شريط الأدوات العلوي، والشريط الجانبي، ومفتاح الاختصار السريع `F1`.
- **طباعة اقتصادية مريحة (Ink-Saving Light Mode):** دعم طباعة الدليل الرسمي بنمط فاتح وعالي التباين يوفر الحبر ومناسب للاستخدام الميداني ولجان التوزيع.

### 3. 👨‍💻 نافذة التواصل مع المطور والدعم الفني المباشر (Developer Contact)
- **ملف تعريفي رسمي للمطور:** تقديم المطور **نصرالدين حداد (Nasreddine Haddad)** - مطور برمجيات شامل (Développeur Full-Stack).
- **قنوات اتصال مباشرة وسريعة:** الهاتف والواتساب، البريد الإلكتروني الرسمي، الحساب على GitHub، وروابط المواقع ومعارض الأعمال مع إمكانية النسخ بنقرة زر.
- **خدمات وحلول رقمية مخصصة:** استعراض الخدمات والحلول البرمجية الاحترافية للشركات والمؤسسات والمهنيين (تطبيقات سطح المكتب، تطبيقات الويب السحابية، وأنظمة التسيير الإداري والتجاري المخصصة).

## 🛠️ دليل المطورين (Development Guide)

إذا كنت ترغب في المساهمة في تطوير المنظومة أو بناء النسخة محلياً من المصدر:

### 1. المتطلبات المسبقة
- **[Node.js](https://nodejs.org/):** الإصدار 18 أو أحدث مع `npm`.
- **[Rust & Cargo](https://rustup.rs/):** الإصدار الثابت (Stable Toolchain).
- **Microsoft C++ Build Tools:** تتوفر عبر Visual Studio Installer (مطلوبة لتجميع حزم Rust على Windows).
- **الهدف 32-بت (اختياري للبناء الموسع):**  
  ```bash
  rustup target add i686-pc-windows-msvc
  ```

### 2. خطوات التثبيت والتشغيل المحلي
```bash
# 1. استنساخ المستودع
git clone https://github.com/nacerdev213/mahfedha-aid.git
cd mahfedha-aid

# 2. تثبيت الحزم والمكتبات
npm install

# 3. تشغيل بيئة تطوير الويب السريعة (Vite Preview)
npm run dev

# 4. تشغيل التطبيق في بيئة سطح المكتب مع المحرك الأصلي (Tauri Dev)
npx tauri dev
```

### 3. بناء حزم التوزيع والإنتاج (Release Build)
```bash
# بناء نسخة 32-bit سريعة:
npm run build:32

# بناء حزم التثبيت الكاملة (Setup EXE + MSI):
npm run build:32:installer
```
تجد الملفات الناتجة القابلة للتثبيت والتوزيع في المسار:
```
src-tauri/target/i686-pc-windows-msvc/release/bundle/
```

## 🏛️ التقنيات المستخدمة (Tech Stack)

| المجال | التقنية | الاستخدام |
| :--- | :--- | :--- |
| **محرك سطح المكتب** | [Tauri](https://tauri.app/) | بناء تطبيقات سطح مكتب فائقة الأداء وخفيفة الحجم |
| **لغة النظام الخلفي** | [Rust](https://www.rust-lang.org/) | إدارة الملفات، التشفير، والتعامل الآمن مع قاعدة البيانات |
| **قاعدة البيانات** | [SQLite](https://www.sqlite.org/) | حفظ واستعلام السجلات محلياً بدون خادم |
| **واجهة المستخدم** | [Vue 3](https://vuejs.org/) + [Vite](https://vitejs.dev/) | بناء واجهات تفاعلية سريعة وحديثة |
| **إدارة الحالة** | [Pinia](https://pinia.vuejs.org/) | إدارة مركزية لحالة المواسم، الحالات الاجتماعية، والمستفيدين |
| **التنسيق والتصميم** | [Tailwind CSS](https://tailwindcss.com/) | تصميم عصري متناسق مع دعم RTL وخط Cairo |
| **معالجة الصور** | [Cropper.js](https://fengyuanchen.github.io/cropperjs/) | قص تفاعلي دقيق لصور المستفيدين بنسبة 1:1 |
| **التشفير والأمان** | [AES-256-GCM](https://crates.io/crates/aes-gcm) + [SHA-2](https://crates.io/crates/sha2) | تشفير وحماية حزم النسخ الاحتياطي `.scaid` |
| **التعامل مع Excel** | [ExcelJS](https://github.com/exceljs/exceljs) + [SheetJS (xlsx)](https://sheetjs.com/) | توليد القوالب ذات القوائم المنسدلة والاستيراد والتصدير |
